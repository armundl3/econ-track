# Econ Track Backlog

## Phase 2: Market Context Dashboard

### Goal
Evolve Econ Track from a personal DCA allocation dashboard into a compact market-context dashboard inspired by Finviz: dense, scannable, table-forward, and focused on signals that affect ETF allocation decisions.

## P1: Macro And News Context

- Add a static macro/news section generated by the Python data job.
- Data sources to evaluate:
  - BLS Public Data API for CPI, unemployment, payroll, wage, and PPI series.
  - BLS release calendar/RSS for upcoming/recent labor and inflation releases.
  - Public market/news RSS feeds for finance headlines, preferring sources with stable RSS or JSON feeds.
- Start with deterministic macro indicators before free-form news:
  - CPI inflation trend.
  - Unemployment rate trend.
  - Nonfarm payrolls trend.
  - Average hourly earnings trend.
  - VIX regime.
  - 10Y Treasury proxy if a public source is available through the existing market provider.
- Add a simple signifier:
  - `market-positive`
  - `market-neutral`
  - `market-negative`
- Classification rules should be transparent and conservative:
  - Lower inflation vs prior/expectation: usually positive.
  - Higher unemployment or payroll weakness: usually negative unless it lowers rate-pressure.
  - Elevated VIX: negative/risk-off.
  - Falling yields: mixed; positive for duration-sensitive growth, negative if driven by recession fear.
- Acceptance:
  - Macro cards render even if news fetch fails.
  - Source and timestamp are shown for every macro/news item.
  - Tests cover signifier classification for representative macro scenarios.
